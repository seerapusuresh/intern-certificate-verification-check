SIX-INTERN CERTIFICATE VERIFICATION DEMO

1. Replace the six records in script.js with your intern details.
2. Put the project on any static web host.
3. The six QR images currently point to:
   https://YOUR-DOMAIN.example/verification/
4. After you know your real public URL, regenerate the QR images using that URL.
5. All six QR codes intentionally open the SAME verification page.
6. The entered name/email/domain identify which certificate is returned.
7. The demo contains no database, backend, admin panel, login, IP tracking, or location tracking.

The included PDF certificates are DEMO placeholders. Replace them with your own certificate PDFs when ready.
